How to run this project:

- Download the model from [huggingface](https://huggingface.co/sunjiao/osea), and place it in `/src`.
- Download [AVONET](https://onlinelibrary.wiley.com/doi/10.1111/ele.13898), and extract it to `/src` (delete the folder `_MACOSX`).
- Download birdtree trees with the script `download.sh`.
- Download [Stiller's tree](https://www.nature.com/articles/s41586-024-07323-1) and place it in the same dir (`CombinedTrees`).
